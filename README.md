# AURIX Brand Guide

Минималистичный web-гайд фирменного стиля AURIX.

Live: https://aurix.ivankamaldinov.workers.dev

По брендбуку используются только две фирменные гарнитуры: Guild A Display и TT Hoves Pro. Палитра интерфейса строится на #1F0048, #A7A4DF и #E9E9F5; типографика — только темно-фиолетовая или белая в зависимости от фона.
